# 隐私安全政策与数据保护承诺

::: tip ⚡ 零个人日志留存原则
**梯子云（tizicloud.blog）** 严格恪守现代网络安全与个人数据隐私保护标准。作为以静态纯文档技术（VitePress）构建的知识分享平台，我们**不强制要求用户注册、不收集个人身份信息、不植入跨站广告追踪脚本**。
:::

---

## 🔒 一、我们收集与不收集的数据

### 1. 我们绝不收集的信息
- **不收集个人敏感真实身份**：我们不设立会员中心，不收集用户的真实姓名、手机号码、身份证号或银行卡金融信息；
- **不记录用户网络浏览历史**：作为资讯与技术文档博客，我们无法也不可能窥探用户在代理隧道内部的任何网络访问活动或通信数据；
- **不贩卖任何用户数据**：我们严禁向任何第三方商业广告联盟、数据中介或经纪机构出售、出租或分享任何访客行为数据。

### 2. 服务器可能产生的必要技术日志
当您访问本网站时，托管静态页面的 Web 服务器（如 Apache / Nginx）可能会生成基础的标准访问日志：
- **访问日志条目**：包括您的公网 IP 地址（已进行脱敏处理）、浏览器 User-Agent 字符串、请求的页面 URL 路径、访问时间戳及 HTTP 响应状态码；
- **用途与保留周期**：此类技术日志仅用于抵御恶意分布式拒绝服务攻击（DDoS）、排查 404 错误与保障服务器基础通信安全，通常在 7 至 14 天内自动循环滚动并彻底销毁。

## 🍪 二、Cookie 与本地存储 (Local Storage) 使用说明

梯子云仅使用为了维持网站正常界面交互所需的必要性客户端本地存储：
- **主题偏好记忆**：用于记录您选择的界面显示模式（深色模式 Dark Mode 或浅色模式 Light Mode）；
- **站内本地搜索缓存**：用于存储 MiniSearch 本地轻量化搜索索引，使您无需向远程服务器发起检索请求即可实现毫秒级纯本地文章搜索；
- **无第三方广告 Cookie**：本站未植入 Google AdSense、百度联盟等跨站行为追踪 Cookie。

## 🛡️ 三、外部商业链接与第三方服务政策

当您点击文章内的第三方官网注册通道（如光速云、暮光加速、飞猫云）时，您将被重定向至第三方服务商的官方站点：
- **独立隐私政策管辖**：一旦离开梯子云域名，您的个人信息保护将受该第三方服务商自身的隐私政策管辖；
- **防跟踪保护**：本站所有出站链接均添加了 `rel="noopener"`，阻止新打开的第三方窗口获取对本站页面的引用（`window.opener`），保障您的会话安全性。

梯子云可能会根据法律法规更迭或网站功能扩展适时修订本隐私政策。任何修订均会在此页面公示最新生效日期。若您对本站的隐私保护规范有任何疑问或合规建议，欢迎查阅 [关于我们](/about/) 页面或通过官方技术交流渠道与实验室取得联系。

### 1. 深度包嗅探与凭证劫持（Credential Harvesting）
许多由黑产团队故意释放出的免费节点，在服务端网关层面部署了深度流量嗅探脚本。当用户的终端设备通过该节点发起网络请求时：
- 节点网关会对非全站 HSTS 保护的域名发起 **SSL 证书降级攻击（SSL Stripping）**，将安全的 HTTPS 请求强行降级为明文 HTTP 通信；
- 哪怕通信内容采用了 TLS 加密，恶意服务端依然可以记录并分析您发起请求的全部域名清单、访问频次、在线时间段以及设备的操作系统指纹；
- 一旦用户输入了社交媒体（Telegram、Twitter、Discord）的登录验证码或 Session Token，攻击者可在数秒钟内完成账号克隆，利用您的身份向亲友发起诈骗或向通讯录群发垃圾广告。

### 2. 充当黑客网络犯罪的“替罪羊”肉鸡（Botnet Proxies）
为什么黑客组织热衷于搭建所谓的“公益免费代理池”？因为他们需要海量的真实客户端 IP 来分散自身发起网络反侦查的足迹：
- 当您连接上某个免费节点时，该节点的服务端往往配置了“反向代理回流管道”，将外部黑客发起的端口扫描、SQL 注入、DDoS 攻击流量与您的正常浏览流量混杂在一起送向目标服务器；
- 在执法机构与海外云安全厂商的溯源日志中，您的设备 IP 极易被判定为协同攻击的“僵尸肉鸡”，导致您的家庭宽带公网 IP 被永久列入国际反垃圾邮件与黑客数据库，严重影响正常互联网业务。

### 3. 剪贴板监听与虚拟货币充值地址篡改
这是近年来针对加密货币投资者的最新型暴利黑产攻击手段：
- 攻击者通过恶意免费节点在传输数据流中动态注入一段轻量级的 JavaScript 代码；

### Q9：使用免费节点会不会消耗我本地手机的流量卡资费？
答：使用代理并不能突破电信运营商的物理流量计费。只要您使用的是蜂窝移动数据（4G/5G），哪怕连接的是免费节点，手机发送和接收每一个数据包依然要经过电信运营商的基站，完全按照您手机卡的原有流量套餐扣费。市面上某些宣称“使用免费代理节点可以实现手机免流、无限白嫖运营商流量”的教程，绝大多数是利用运营商早期计费漏洞（如伪造 Host 头部走咪咕、营业厅免流通道）的黑客手法，目前运营商已对该漏洞进行了全面修补，切勿轻易尝试以免导致手机卡被系统停机或扣费超支。

### Q10：在电脑上尝试过免费节点后，如何确保系统没有残留木马或恶意证书？
